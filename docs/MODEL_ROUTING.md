# 模型分工规则（全自动路由）

这份文件告诉你（运行中的 Claude）什么时候该自己干、什么时候该叫顾问、什么时候该派廉价子代理。
用户不需要手动选模型——路由已经固化在配置和脚本里。

## 三层结构

| 层 | 是谁 | 怎么触发 | 成本量级 |
|---|---|---|---|
| **执行层** | 主会话（DeepSeek v4-flash） | 默认，你就在这层 | 最低 |
| **判断层** | Opus 顾问，`opus-consult.ps1` | 你在执行中遇到下面的「该叫顾问」情形 | 一次 2–5 美分 |
| **苦力层** | `scout` 子代理（haiku） | 搜代码、读多个文件、批量机械活 | 极低 |

## 该叫顾问（Opus）的情形

用 `powershell -File %USERPROFILE%\.claude\tools\opus-consult.ps1 "问题" -Files 文件1,文件2`。

只在**判断出错代价高、而你又不确定**时叫：

- 同一个 bug 改了两次还没好 → 先停手，把症状 + 你试过什么交给顾问，不要试第三次。
- 要做架构级取舍（选方案 A 还是 B），且两条路都会带来明显代价。
- 代码审阅要判断「这是不是真缺陷」——不是找风格问题。
- 用户问「为什么会这样」「该往哪个方向修」这类需要推理而非查找的问题。
- 现有方案看起来对但结论反直觉时（比如指标说没用，但你怀疑是测错了）。

**不要叫顾问的情形**：文件在哪、这段代码写了什么、跑个命令看输出、按已定方案改代码、写 changelog、重命名。这些你自己做或者派 scout。

## 叫顾问时必须遵守

1. **只送相关文件**。`-Files` 里最多 3–5 个真正相关的，别把整个项目塞过去——顾问的价值就在于上下文干净。
2. **预算默认 0.5 美元**。诊断类超了说明问题没拆够，先拆分再问。
3. **`-Effort`**：普通问题 `low` 或 `medium`（默认）；真的很难再上 `high`。思考 token 是主要成本。
4. **把顾问的结论当成建议，不是命令**。它看不到你的完整上下文，可能漏掉约束。执行前自己判断一遍。
5. **别把顾问的话原样转发给用户**。消化后转述，用户不需要看到中间过程。
6. **代理没开时**：脚本会先试着拉起 Pigeon；确实连不上就加 `-FallbackFlash` 让 Flash 兜底，避免任务卡死。但兜底结果不是判断层，ledger 里 `degraded=true`，只能当草稿。

## 派 scout 子代理的情形

- 要在多个文件里找东西、要读一堆文件才回答得上来
- 批量机械改动（重命名、迁移调用、改文档里的数字）
- 按已写好的 spec 逐条实现，每一步都有能跑的验收命令

**派之前必须给它一条能验证的验收标准**（`pytest tests/test_x.py -q` 之类）。没有验收标准的活不许外包——它会自信地做错。

## 升级规则（硬性）

- scout 在同一处失败两次 → 停手，向上报告，不要试第三次。
- 你（执行层）同一个问题改两次没好 → 叫顾问，不要试第三次。
- 顾问说「需要看 X」→ 你先去把 X 取来（用 scout），再问一次，不要空手重复问。

## 上下文纪律

- 压缩窗口设在 160k（约 147k 触发）。压缩之前，PostCompact hook 会自动把摘要写进交接文件；新会话启动时自动读回。**所以压缩不怕丢线索，不用为了怕丢而不敢压。**
- 真正需要保留的结论，主动写进项目的 `HANDOFF.md` 或 `progress.md`，别指望上下文活着。
- 一个任务做完了就 `/clear`，别在同一个会话里接着干第二件事。会话越长，每一轮越贵，而且你对重点的把握会下降。

## 记账

- 顾问调用自动记到 `%USERPROFILE%\.claude\ledger\consult.jsonl`
- 查看当天花费：`claude-usage.ps1`（见同目录 tools）

## 双模型通道（2026-10-26 新增）

桌面快捷方式「Claude Code（Flash × Opus 协作）」是这条规则的白名单版本：只允许两个模型。

| 文件 | 作用 |
|---|---|
| `claude-duo.ps1` | 启动器：查代理 → 打印通道信息 → 用下面两个文件起 claude（带 `--dangerously-skip-permissions`） |
| `settings-duo.json` | 把 opus / sonnet / haiku / fable 四个别名全部指向 `deepseek-v4-flash[1M]`。`--settings` 是**叠加**，只覆盖同名 env 键，不替换 `settings.json` |
| `duo-policy.md` | 经 `--append-system-prompt-file` 注入每次会话，告诉模型本通道只有 Flash + Opus 顾问，禁止用 `chief` 做判断 |

这条通道里 `scout` 的 `model: haiku` 和 `chief` 的 `model: opus` 都会落到 Flash（别名被改写），所以两者都只是"另一个 Flash"；判断一律走 `opus-consult.ps1`。其他入口不受影响。
